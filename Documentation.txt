NAME

main.py - Compare the similarity of two songs

SYNOPSIS

python main.py [-h] [-f filename] [-S directory] [-p] [-c variable=value [variable=value ...]]

DESCRIPTION

main.py is a command-line tool for comparing the similarity of two songs based on their frequency compositions. It processes audio files to extract frequency characteristics and compares them using mathematical algorithms. The comparison results are stored for later analysis and can be used to generate playlists.

OPTIONS

- -h, --help: Show the help message and exit.

- -f filename, --file filename: Specify the file to compare.

- -S directory, --Scan directory: Directory to scan for songs. The tool will process all .mp3 files found in the specified directory.

- -p, --play: Play a playlist generated based on the comparison results.

- -c variable=value [variable=value ...], --config variable=value [variable=value ...]: Change variable values. Available variables are 'S' for SongData path, 'C' for CompData path, and 'D' for SongFile directory.

EXAMPLES

1. Show song comparison:

python main.py -f song1.mp3

2. Scan a directory for songs:

python main.py -S /path/to/directory

3. Compare songs and play a playlist:

python main.py -f song2.mp3 -p

4. Change variable values:

python main.py -f song3.mp3 -c S=new_song_data.csv C=new_comp_data.csv D=/path/to/songs
